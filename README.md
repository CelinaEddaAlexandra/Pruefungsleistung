# Prüfungsleistung Praxisseminar

## LLM-gestützte Entwicklung eines wissenschaftlich fundierten Fragebogens

Dieses Repository dokumentiert die iterative Entwicklung und Evaluation
eines Masterprompts zur theoriegeleiteten Erstellung eines quantitativen
Fragebogens mithilfe eines Large Language Models.
